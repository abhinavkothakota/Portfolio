# Portfolio Website - Kothakota Abhinav

A modern, responsive personal portfolio website built with React.js, showcasing professional skills, projects, and contact information.

## 📝 Description

This is a comprehensive personal portfolio website designed to showcase professional work, skills, and personality. The website serves as a digital resume and creative platform for **Kothakota Abhinav**, a Frontend Web Developer and Computer Science student from Hyderabad, India.

### Purpose
- **Professional Showcase**: Display technical skills, projects, and achievements
- **Personal Branding**: Create a strong online presence and professional identity
- **Career Development**: Attract potential employers, clients, and collaborators
- **Creative Expression**: Demonstrate design skills and technical capabilities

### Target Audience
- Potential employers and recruiters
- Clients looking for web development services
- Fellow developers and tech community
- Professional network and collaborators

### Key Highlights
- **Student Portfolio**: Showcases work from a Computer Science student perspective
- **Frontend Focus**: Emphasizes web development and UI/UX design skills
- **Interactive Experience**: Engaging animations and smooth user interactions
- **Mobile-First**: Optimized for all devices and screen sizes
- **Professional Presentation**: Clean, modern design that reflects technical competence

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Interactive Elements**: 
  - Typewriter effect for dynamic text
  - Parallax tilt effects
  - Smooth page transitions
  - Loading spinner
- **Multi-page Navigation**: 
  - Home page with introduction
  - About page with skills showcase
  - Projects portfolio
  - Contact form
- **Social Media Integration**: Links to GitHub, LinkedIn, Instagram, and email
- **Resume Download**: Direct download link for resume

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/portfolio-website.git
   cd portfolio-website
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to view the website

### Build for Production

```bash
npm run build
# or
yarn build
```

The built files will be in the `dist` directory.

## 🎨 Customization

### Personal Information
Update the following files with your information:

1. **Home.jsx** - Change name and introduction
2. **About.jsx** - Update personal details and resume link
3. **Footer.jsx** - Update social media links
4. **ProjectBox.jsx** - Add your projects and descriptions

### Styling
- **Color Scheme**: Modify the CSS variable `--color` in `index.css`
- **Fonts**: Change the Google Fonts import in `index.html`
- **Layout**: Customize component styles in respective CSS files

### Images
Replace the following images in the `src/images/` directory:
- `Avatar.png` - Your profile picture
- `CarPoint.png` - Project screenshots
- `FoodApp.png` - Project screenshots
